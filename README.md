## ✨ Возможности

### 🗺️ Квесты
- **3 уникальных квеста** с нарастающей сложностью — от новичка до детектива
- Каждый квест: пошаговые задания, GPS-подсказки, описания мест
- Живой таймер и пошаговый прогресс-бар
- Диалог подсказки 💡 в любой момент

### 🎮 Мини-игра: «Найди исчезнувшее»
- **Фаза запоминания** — карточки появляются каскадом, отсчёт 6 секунд
- **Фаза открытия** — один предмет исчезает, анимированный пустой слот пульсирует
- **Фаза угадывания** — 15 секунд, 3 жизни, тряска при ошибке, вспышка при переходе
- **Haptic feedback** — телефон вибрирует при правильном/неверном ответе
- Очки зависят от скорости и оставшихся жизней

### 🏆 Прогрессия
| Уровень | Название | Требование |
|---------|----------|------------|
| 1–2 | 🌱 Новичок | Начало |
| 3–4 | 🔥 Путешественник | Уровень 3+ |
| 5–6 | ⭐ Исследователь Б-корпуса | Уровень 5+ |
| 7–9 | 🏆 Мастер-исследователь | Уровень 7+ |
| 10+ | 👑 Легенда Б-корпуса | Уровень 10+ |

### 🗺️ Интерактивная карта
- Схема 1-го этажа с реальной планировкой
- Pinch-to-zoom, панорамирование
- Нажатие на комнату → описание
- Цветовое кодирование: аудитории / лаборатории / общественные / лестницы

### 🎊 Конфетти
- При завершении каждого квеста — анимация конфетти из 80 частиц
- Диалог с эмодзи квеста, статистикой XP / времени / заданий

### 👤 Профиль
- Серия дней подряд 🔥
- 4 показателя статистики
- 6 разблокируемых достижений
- Кольцо прогресса уровня с анимацией

## 🏗️ Архитектура

```
lib/
├── main.dart                          # Точка входа, тема
├── data/
│   ├── quest_data.dart                # Контент квестов и заданий
│   └── app_state.dart                 # Глобальное состояние (singleton + ChangeNotifier)
├── screens/
│   ├── home_screen.dart               # Главный экран
│   ├── quest_list_screen.dart         # Список квестов
│   ├── quest_detail_screen.dart       # Детали квеста
│   ├── quest_execution_screen.dart    # Прохождение квеста
│   ├── map_screen.dart                # Интерактивная карта
│   └── profile_screen.dart           # Профиль и достижения
├── game/
│   └── disappeared_game.dart         # Мини-игра «Найди исчезнувшее»
└── widgets/
    ├── common_widgets.dart            # Переиспользуемые компоненты
    └── confetti_widget.dart           # Анимация конфетти
```

### Паттерны
- **Singleton + ChangeNotifier** — простое глобальное состояние без лишних зависимостей
- **TickerProviderStateMixin** — множественные анимационные контроллеры в одном виджете
- **CustomPainter** — карта и конфетти отрисовываются напрямую на canvas
- **AnimatedSwitcher** — плавные переходы между фазами мини-игры

## 🚀 Установка и запуск

### Требования
- Flutter SDK `>= 3.0.0`
- Dart SDK `>= 3.0.0`
- Android Studio / VS Code с расширением Flutter

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_USERNAME/bcorp_quest.git
cd bcorp_quest

# 2. Установить зависимости
flutter pub get

# 3. Запустить приложение
flutter run

# 4. Собрать APK
flutter build apk --release
```

### pubspec.yaml
Приложение использует **только стандартные пакеты Flutter** — никаких сторонних зависимостей не нужно.

## 👨‍💻 Разработка

### Добавить новый квест
В файле `lib/data/quest_data.dart` добавь объект `Quest` в список `QuestData.quests`:

```dart
Quest(
  id: 'quest_4',
  title: 'Мой новый квест',
  emoji: '🎯',
  // ...
  tasks: [
    QuestTask(
      miniGameType: MiniGameType.disappeared,
      miniGameItems: ['Предмет1', 'Предмет2', ...],
      // ...
    ),
  ],
)
```

### Добавить мини-игру в задание
```dart
miniGameType: MiniGameType.disappeared,
miniGameItems: ['Книга', 'Ручка', 'Стол', 'Лампа', 'Папка', 'Значок'],
```
