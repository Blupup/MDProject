## 📱 О приложении

**Б-Корпус Квест** — это интерактивный гид по зданию в формате игры. Студент проходит квесты, находит реальные места в корпусе, читает их историю и играет в мини-игры прямо на месте. Чем больше исследуешь — тем выше уровень и больше достижений.

> 🎯 Цель: сделать знакомство с корпусом весёлым, а не скучным

---

## ✨ Возможности

### 🗺️ Квесты

Три квеста с нарастающей сложностью. В каждом — пошаговые задания с реальными местами корпуса.

| Квест | Сложность | Заданий | XP | Описание |
|-------|-----------|---------|-----|----------|
| 🗺️ Знакомство с Б-корпусом | 🌱 Новичок | 3 | 150 | Найди главные места первого этажа |
| 📜 Исторический маршрут | 🔥 Средний | 4 | 300 | Погрузись в историю университета |
| 🔬 Технический детектив | ⚡ Сложный | 3 | 450 | Исследуй лаборатории и найди артефакты |

**Фичи каждого задания:**
- 📸 Фотография места с историческим описанием
- 💡 Подсказка по требованию — не даст заблудиться
- 🎮 Кнопка выбора мини-игры для заданий с геймплеем
- ✅ Пошаговый прогресс, конфетти при завершении квеста

---

### 🎮 Мини-игры — 5 штук на выбор

На каждом задании с игрой открывается экран выбора из **5 мини-игр**. Победа в любой засчитывает задание.

---

#### 👁️ Найди исчезнувшее
> *Сложность: Средняя*

Карточки с предметами появляются каскадом. Запомни их все — один пропадёт. Угадай какой!

- ⏱️ 6 секунд на запоминание → 15 секунд на ответ  
- ❤️ 3 жизни, тряска экрана при ошибке  
- 📳 Haptic feedback при каждом действии  
- 🏆 Очки зависят от скорости и оставшихся жизней  

---

#### 🃏 Найди пары
> *Сложность: Лёгкая*

Классические карточки памяти. Переворачивай и ищи одинаковые пары — с фотографиями мест корпуса.

- 🔄 Анимация переворота карточки (Matrix4 3D-эффект)  
- ⏱️ Таймер 60 секунд  
- ❤️ 3 жизни  
- 📸 Работает с твоими фотографиями или цветными заглушками  

---

#### 🧩 Пятнашки
> *Сложность: Сложная*

Собери разрезанное фото из 12 кусочков (3×4). Перетаскивай фрагменты на нужные места.

- ⏱️ 2 минуты на сборку  
- ✅ Зелёная рамка подсвечивает правильно стоящие кусочки  
- 📸 Использует твои фото или цветные плашки  
- 🔀 Гарантированно решаемая конфигурация  

---

#### 🔤 Собери слово
> *Сложность: Средняя*

Из перемешанных букв составь правильное слово — название предмета из задания.

- ⏱️ 30 секунд на каждое слово  
- 📳 Тряска при ошибке  
- 📝 Использует слова из `miniGameItems` задания  
- 🔁 Несколько слов за сессию  

---

#### 🚀 Межпланетный прыжок
> *Бонусная игра*

Студент вращается вокруг планеты-этажа. Нажми в нужный момент — он полетит по касательной. Попади в следующую планету!

- 🪐 Планеты = места Б-корпуса (1 этаж, Лаборатория, Библиотека...)  
- ☝️ Летишь строго по касательной — нужно поймать правильный угол  
- 🌟 Звёзды мерцают, туманности светятся, хвост полёта  
- ❤️ 3 жизни, ускорение орбиты с каждой планетой  
- 🔥 Комбо-счётчик за подряд удачные прыжки  
- 🏆 Победа: долететь до 8 планет  

---

### 🏆 Система прогрессии

```
Уровень 1–2  ............  🌱 Новичок
Уровень 3–4  ............  🔥 Путешественник  
Уровень 5–6  ............  ⭐ Исследователь Б-корпуса
Уровень 7–9  ............  🏆 Мастер-исследователь
Уровень 10+  ............  👑 Легенда Б-корпуса
```

**Достижения:**

| Иконка | Название | Условие |
|--------|----------|---------|
| 🚩 | Первые шаги | Завершить первый квест |
| 🧭 | Исследователь | Завершить 2 квеста |
| 💎 | Мастер | Завершить все квесты |
| ⚡ | Спидраннер | Набрать 500 XP |
| ✅ | Преданный | Выполнить 10 заданий |

### 🗺️ Интерактивная карта

- Схема 1-го этажа с реальной планировкой корпуса  
- Pinch-to-zoom и панорамирование  
- Нажатие на комнату → всплывающее описание  
- Цветовое кодирование по типу помещений  

| Цвет | Тип |
|------|-----|
| 🔵 Синий | Аудитории |
| 🟢 Зелёный | Лаборатории |
| 🟡 Жёлтый | Общественные пространства |
| 🔴 Красный | Лестницы |
| 💚 Светло-зелёный | Туалеты |

### 🎊 Конфетти и анимации

- При завершении каждого квеста — взрыв из 80 разноцветных частиц  
- Плавные входные анимации на всех экранах  
- Каскадное появление карточек в мини-играх  
- Пульсирующие планеты и мерцающие звёзды в раннере

## 🏗️ Архитектура

```
lib/
├── main.dart
├── data/
│   ├── quest_data.dart          # Контент квестов, заданий, фото
│   └── app_state.dart           # Глобальное состояние (Singleton + ChangeNotifier)
├── screens/
│   ├── home_screen.dart         # Главный экран с XP-картой
│   ├── quest_list_screen.dart   # Список квестов с прогрессом
│   ├── quest_detail_screen.dart # Детали и превью заданий
│   ├── quest_execution_screen.dart  # Прохождение: фото, история, кнопка игры
│   ├── game_selection_screen.dart   # Выбор одной из 5 мини-игр
│   ├── map_screen.dart          # Интерактивная карта этажа
│   └── profile_screen.dart      # Профиль, статистика, достижения
├── game/
│   ├── disappeared_game.dart    # 👁️ Найди исчезнувшее
│   ├── memory_pairs_game.dart   # 🃏 Найди пары
│   ├── puzzle_game.dart         # 🧩 Пятнашки
│   ├── word_scramble_game.dart  # 🔤 Собери слово
│   ├── corridor_runner_game.dart # 🎓 Коридорный раннер
│   └── planet_hop_game.dart     # 🚀 Межпланетный прыжок
└── widgets/
    ├── common_widgets.dart      # GradientButton, AppCard, XpBadge...
    └── confetti_widget.dart     # Анимация конфетти (CustomPainter)
```

### Паттерны и технологии

| Паттерн | Где используется |
|---------|-----------------|
| `Singleton + ChangeNotifier` | Глобальное состояние без лишних зависимостей |
| `TickerProviderStateMixin` | Множественные анимации в одном виджете |
| `CustomPainter` | Карта, конфетти, игровые поля раннера и прыжка |
| `AnimatedBuilder` | Игровой цикл 60fps через AnimationController |
| `Stack + Positioned.fill` | Оверлеи победы/поражения поверх игрового поля |

## 📸 Добавление своих фотографий

```
1. Создай папку  assets/images/  в корне проекта
2. Положи фото:  assets/images/location_entrance.jpg
3. Добавь в pubspec.yaml:
       flutter:
         assets:
           - assets/images/

4. В quest_data.dart укажи путь:
       locationPhoto: 'assets/images/location_entrance.jpg'
       puzzlePhoto:   'assets/images/puzzle_entrance.jpg'
       pairPhotos:    ['assets/images/pairs_1.jpg', ...]
```

Если фото не указано — игры работают с **цветными заглушками** для тестирования.

---

## ✏️ Как добавить новый квест

В `lib/data/quest_data.dart` добавь объект `Quest` в список `QuestData.quests`:

```dart
Quest(
  id: 'quest_4',
  title: 'Мой новый квест',
  emoji: '🎯',
  duration: '45 мин',
  difficulty: 'Средний',
  difficultyLevel: 2,
  taskCount: 3,
  xpReward: 300,
  tasks: [
    QuestTask(
      number: 1,
      title: 'Название места',
      description: 'Найди это место...',
      hint: 'Подсказка где искать',
      location: '2 этаж, ауд. 201',
      icon: Icons.room_rounded,
      locationStory: 'История этого места...',
      locationPhoto: 'assets/images/location_201.jpg',  // или null
      miniGameType: MiniGameType.disappeared,
      miniGameItems: ['Книга', 'Ручка', 'Стол', 'Лампа', 'Папка', 'Значок'],
      pairPhotos: [],    // фото для игры «Пары»
      puzzlePhoto: null, // фото для «Пятнашек»
    ),
  ],
)
```
